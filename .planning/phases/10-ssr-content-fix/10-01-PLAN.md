The single canonical data-accessor pattern in this codebase (analog for getPortfolioData.ts) —
from my-app/src/app/i18n/usePortfolioData.ts (full file, 16 lines):
```typescript
"use client";

import en from "../../../public/locales/en/common.json";
import es from "../../../public/locales/es/common.json";
import type { PortfolioData } from "./portfolio.types";

const LOCALES: Record<string, PortfolioData> = {
  en: en as unknown as PortfolioData,
  es: es as unknown as PortfolioData,
};

export function usePortfolioData(lng: string) {
  const data = LOCALES[lng] ?? LOCALES.en;
  return { data, ready: true };
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route param → data accessor | `lang` arrives from the `[lang]` route segment (enumerated `["en","es"]` by `generateStaticParams` in i18n-config.ts) and is used only as a key into the static `LOCALES` map |

## STRIDE Threat Register

This phase introduces NO new attack surface: it removes a client-side translation library (i18next), renames one static JSON key, and swaps the source of one URL string from a translation table to an already-bundled static object. No new user input, auth, session, network, or cryptography is added. The JSON-LD / `dangerouslySetInnerHTML` work is Phase 13, not here. The spinner removal exposes already-static, build-time content — no new data is surfaced.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | `getPortfolioData(lang)` / `usePortfolioData(lang)` — unexpected `lang` value | accept | Pre-existing `LOCALES[lang] ?? LOCALES.en` fallback safely defaults to `en`; `lang` is never used in a query, file path beyond the static import map, or shell command — no injection vector. `lang` is already constrained to `["en","es"]` upstream by generateStaticParams. |
| T-10-02 | Information Disclosure | Initial SSR HTML now contains full portfolio content | accept | This is the explicit, intended goal (SSR-01). All exposed content is already-public, build-time static JSON meant for crawlers — no secrets, PII, or non-public data is in `common.json`. |
| T-10-SC | Tampering | npm install (supply chain) | n/a | No package is INSTALLED in this plan — the only dependency operation in this phase is `npm uninstall` (Plan 02), which removes attack surface. The Package Legitimacy Gate applies to new installs and is not applicable. |
</threat_model>
