## What changed in source

- **Framework upgrade**: Next 14 → 16, React 18 → 19, framer-motion 11 → 12
  - Codemods: `cookies()` async, `params: Promise<>` async, `easings` → `ease`, removed dead `@ts-expect-error` directives, removed broken `addVariablesForColors` Tailwind plugin (Turbopack-incompatible), stripped `: any` annotations from `tailwind.config.js`
- **Stack swap**: `@nextui-org/react` → `@heroui/react@2.8.x`, `@splinetool/react-spline` → removed (placeholder for Phase 5 voxel)
- **Files modified**: 10 (`providers.tsx`, `tailwind.config.js`, `Landing.tsx`, `ProyectCard.tsx`, `SendEmail.tsx`, `Adress.tsx`, `LangSwitcher.tsx`, `LangLoader.tsx`, `Loader.tsx`, `SideBar.tsx`)
