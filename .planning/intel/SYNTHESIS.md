## Project Summary

**Portfolio v2.0.0** is a visual redesign of `tomas.dev` — a personal portfolio for Tomás Pérez (senior frontend dev / architect). The redesign merges a pre-built design system (from Claude Design, at `.claude_design/export/`) into an existing Next.js 14 App Router codebase.

This is a **structural and visual refactor**, not a rewrite. The existing functional pieces (i18n, contact form, Calendly, analytics) are preserved; the heavy dependencies (Spline, NextUI) are replaced.

**Target:** Vercel production. Branch: `v2.0.0`.

---

## Goals

1. Ship a distinct visual identity with strong personality (vs current generic look)
2. Reduce bundle weight ≥30% (Spline + NextUI removal)
3. Preserve and extend ES/EN i18n
4. Maintain contact pipeline (email + calendar + toasts)
5. Improve Core Web Vitals (LCP<2.5s, CLS<0.1, INP<200ms)
6. Lighthouse ≥90 desktop / ≥80 mobile

---

## Locked Decisions (12)

All from SPEC — highest precedence:

1. Keep Next.js 14 App Router
2. Convert JSX → TSX (zero `any` types)
3. Migrate `@nextui-org/react` → `@heroui/react`
4. Replace Spline with voxel CSS 3D
5. Keep Framer Motion as animation engine
6. react-bits: ≤2 components, surgical use only
7. Install HeroUI MCP (`npx -y @heroui/react-mcp`)
8. Install shadcn MCP (`npx shadcn@latest mcp init --client claude`)
9. Keep i18next + `[lang]` routing
10. Keep Nodemailer + Calendly + Sonner
11. Adopt `data-theme` toggle (replaces NextUI theme)
12. Fonts: Bricolage Grotesque + Geist + JetBrains Mono via `next/font`
